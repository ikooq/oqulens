# Заявка на EdTech Hackathon by Zhambyl Hub

## Название проекта
OquLens — Data-Driven Curriculum

## Кейс
Кейс 1. Data-Driven Curriculum: интеллектуальная система оценки эффективности учебников и учебных программ

## Коротко (1–2 предложения)
OquLens — веб-платформа для методистов: по результатам СОР она находит трудные разделы и их первопричину, честно сравнивает учебники с поправкой на состав учеников и предлагает, как перераспределить учебные часы, а затем собирает методическую записку на русском или казахском.

## Описание решения
Методист загружает CSV с результатами суммативного оценивания за разделы (выгрузка из журнала или Excel; заголовки можно писать по-русски). Платформа:

1. **Анализирует результаты по разделам программы:** средний %, уровни освоения, 95% доверительные интервалы, тепловая карта «раздел × район / школа», фильтры по району, городу/селу и языку обучения.
2. **Выявляет трудные разделы и их причину.** Отличает системную проблему (раздел проседает во всех школах) от зависимости от школы (вопрос преподавания). Находит раздел-пререквизит, который тянет вниз следующий: например, среди не освоивших «Формулы сокращённого умножения» 80% проваливают «Алгебраические дроби», среди освоивших — 16%.
3. **Честно сравнивает учебники.** Сравнение идёт при одинаковом стартовом уровне учеников, типе местности и языке обучения, ошибки кластеризованы по школам. Платформа показывает, почему сырой рейтинг вводит в заблуждение, и находит «слабые главы» конкретного учебника. Вместо дорогой смены учебника хватает дополнительных материалов к одной главе.
4. **Даёт обоснованные рекомендации по часам.** Оценивает отдачу от каждого дополнительного часа по разделу и переносит часы в рамках утверждённого объёма, только если выигрыш больше потерь даже в пессимистичном сценарии. Показывает прогноз эффекта, предлагает симулятор «что если» и экспорт плана для КТП.
5. **Собирает методическую записку:** автоматическую (без ИИ) и ИИ-версию на русском или казахском (Claude API). В ИИ уходят только агрегаты, без данных учеников.

Все расчёты выполняются в браузере: персональные данные учеников не покидают компьютер методиста.

**Демо:** синтетические данные — алгебра, 7 класс, 63 школы в 11 районах Жамбылской области, ~2 600 учащихся. В данные заранее заложены 5 закономерностей, и платформа находит все пять сама.

## Технологии
Next.js 15, React 19, TypeScript, Tailwind CSS 4, собственная статистическая библиотека (МНК, кластерно-устойчивые ошибки, ICC), Claude API.
